# RAVENS R4VS — starter website

A responsive, multi-page esports website starter for a Counter-Strike 2 team.

## Pages
- `index.html` — home page
- `roster.html` — active roster and substitutes
- `matches.html` — fixtures and results placeholder
- `achievements.html` — milestones
- `news.html` — team updates
- `join.html` — recruitment information

## Run locally
Open `index.html` in a browser. No build tools or dependencies are required.

## Publish for free with GitHub Pages
1. Create a GitHub repository (for example `ravens-r4vs-site`).
2. Upload all files from this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. GitHub will provide your public website URL after deployment.

## Before publishing
- Replace the generic Discord, TikTok and YouTube links with official Ravens links.
- Add player photos and Steam profile URLs.
- Confirm roster names, roles and recruitment criteria.
- Replace the sample 2026 foundation milestone with verified achievements.
- Add actual fixtures and results when available.

The website uses Google Fonts from an external service. If unavailable, fallback fonts will be used.
